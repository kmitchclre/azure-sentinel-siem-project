#Microsoft Azure Sentinel SIEM Project

## Overview
This project involved implementing Microsoft Sentinel, a cloud-native Security Information and Event Management (SIEM) solution within Microsoft Azure. The goal was to establish centralized security monitoring and improve visibility into potential security threats.

## Technologies Used
- Microsoft Azure
- Microsoft Sentinel
- Log Analytics Workspace
- Kusto Query Language (KQL)

## Project Objectives
- Deploy Microsoft Sentinel within Azure.
- Configure centralized security monitoring.
- Collect and analyze security logs.
- Explore threat detection and security analytics.
- Investigate security events and potential incidents.
